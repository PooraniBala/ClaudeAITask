Run the full test suite with coverage and open the HTML report

## What This Does
Runs Vitest with coverage collection across lib/, app/api/, and components/,
enforces the 90%/85% thresholds defined in vitest.config.ts, and opens the
HTML report so you can see exactly which lines are uncovered.

## Steps

1. Clean previous coverage output:
   Run: Remove-Item -Recurse -Force coverage -ErrorAction SilentlyContinue
   (on macOS/Linux: rm -rf coverage/)
   Ensures the report reflects only the current run, not a stale one.

2. Run the full test suite with coverage:
   Run: pnpm test:coverage
   This executes: vitest run --coverage
   Coverage is collected from: app/api/**, lib/**, components/**
   (as configured in vitest.config.ts — provider: istanbul)

3. Parse the coverage summary from the Vitest output and print a table:

   📊 Coverage Summary
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Layer          | Statements | Functions | Branches
   ────────────────────────────────────────────────
   lib/           |    XX%     |    XX%    |   XX%
   app/api/       |    XX%     |    XX%    |   XX%
   components/    |    XX%     |    XX%    |   XX%
   ────────────────────────────────────────────────
   Overall        |    XX%     |    XX%    |   XX%
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Thresholds     |    90%     |    90%    |   85%

4. Check thresholds (Vitest enforces these automatically via vitest.config.ts):

   If ALL thresholds met:
   ✅ Coverage thresholds passed — safe to merge

   If ANY threshold missed (Vitest will exit non-zero):
   ❌ Coverage below threshold

   List every file reported below threshold:
     Format: "  ❌ lib/github.ts — Statements: 78% (need 90%)"

   Then list the top uncovered functions per failing file:
     Format: "  📍 lib/github.ts:fetchContributors — lines 45-67 uncovered"

5. Open the HTML coverage report:
   On Windows: Start-Process coverage/index.html
   On macOS:   open coverage/index.html
   On Linux:   xdg-open coverage/index.html

   The report is generated by the Istanbul provider into coverage/
   (index.html at coverage/index.html)

6. If coverage is below threshold, provide targeted guidance per failing file:
   For each uncovered line range or branch, suggest the exact test case:
   Example:
   "📝 To cover lib/sync.ts line 34 (McpError catch branch):
    Add test: 'syncRepoMetrics rethrows McpError when GitHub fetch fails'"

## Success Criteria
- All tests pass (zero failures)
- Statements: 90%+ ✅
- Functions:  90%+ ✅
- Branches:   85%+ ✅
- coverage/index.html exists and opens in browser showing green across all files
